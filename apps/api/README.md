# Backend runtime and limits

Development: `MAYUAN_MODE=development MAYUAN_ORIGINS=http://127.0.0.1:4179 php -S 127.0.0.1:8086 -t public public/router.php`. Default storage is `storage/mayuan.sqlite`; override `MAYUAN_DB_DSN=sqlite:/absolute/path.sqlite`. Session cookies are HttpOnly, SameSite=Lax. Every JSON mutation requires a precise allowed Origin, including login. Client user IDs and correctness never authorize writes or grading.

Production: Docker build context is this directory, port9501, Hyperf3.1/Swoole. Set `MAYUAN_DB_DSN=mysql:host=mysql;dbname=mayuan;charset=utf8mb4`, `MAYUAN_DB_USER`, `MAYUAN_DB_PASSWORD`, `MAYUAN_ORIGINS=https://your-frontend`; TLS termination required. Production mode defaults to guanlan, rejects developer identities, refuses SQLite/default credentials. Session runtime volume must persist and be private. PDO table auto-init uses LONGTEXT for MySQL (SQLiteTEXT); user mutation transactions share a serialization lock. For any earlier experimental TEXT table, migrate explicitly `ALTER TABLE mayuan_records MODIFY body LONGTEXT NOT NULL` before importing content.

Hyperf Docker/MySQL target has been authored and PHP syntax checked, not deployed or integration-tested here. Dependency installation and container boot remain production acceptance gates. Session configuration and lifecycle use [official Hyperf3.1 interface](https://github.com/hyperf/hyperf/blob/3.1/src/contract/src/SessionInterface.php) and [session middleware](https://github.com/hyperf/hyperf/blob/3.1/src/session/src/Middleware/SessionMiddleware.php).

Guanlan: `GUANLAN_BASE_URL=https://trusted-host` enables POST `/api/v2/guanlan/validate` `{token}` through server-side `/api/v1/auth/me`; no token in URL. Every subsequent request revalidates identity and active status; verified displayName/id/admin role are mapped server-side. This is explicit token validation, not SSO. Code exchange always returns integration_unconfigured: host snapshot has no implemented one-time protocol.

Summary delivery is dormant by default. Only after the host implements and approves the following future contract set `GUANLAN_SUMMARY_PROTOCOL=mayuan-summary-v1`, `GUANLAN_SUMMARY_URL=https://trusted-host/approved-path`, `GUANLAN_SERVICE_TOKEN` scoped to summary. Worker `php bin/outbox.php` sends PUT JSON schemaVersion1, eventId, revision, subject=`guanlan:<stable-id>`, contentVersion, UTC generatedAt/lastActivityAt, visitedConceptCount, selfAssessedMasteredCount, practiceAttemptCount/practiceCorrectCount, dueReviewCount and resumeTarget. Host must verify service subject mapping and return `{data:{revision:<accepted-number>}}`. Subject mapping is a proposed additional contract, not an existing host capability. No private notes or browser identity token travel in outbox.

Worker retains transactionally stored summary snapshots, supersedes older pending absolute summaries, requires exact acknowledgment revision, retries network/5xx with bounded exponential delay, honors numeric Retry-After for429, pauses401/403 and permanently fails other4xx. Do not schedule worker until actual host contract is available and jointly tested. CLI exits2 when unconfigured. Official host interfaces have not been called; real identity/summary and one-time SSO are unverified.

Imports require authenticated explicit confirmation; V1 statistics must agree with records. Imported objective answers remain historical/unverified and never become trusted grading counts. Occurrence times and self mastery times validated separately from future review due times. State revisions and mutation times are server-owned. Identical import file replay does not duplicate records; immutable event ID replay returns original response, mismatched body conflicts.

Private routes require X-Mayuan-User with the frontend's captured verified principal id. Server compares this precondition with its authenticated session; it never authorizes from this header. Missing or mismatched principal returns409 session_changed and prevents stale tabs/queues from writing another shared-cookie account. /session,/content,/dev-login,/logout,/guanlan/validate are exempt. Anonymous private requests remain401. Re-fetch session and retain the original account queue after an account-change conflict; never automatically replay to the new principal.
