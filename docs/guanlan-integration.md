# 观澜接入说明

日期：2026-10-03。

## 当前边界

本项目先独立开发，观澜工程没有被修改。正式账号来源是观澜，开发模式仅使用显式模拟账号。禁止将开发模式直接作为正式账号服务部署。

宿主需求文档：`D:\code_files\观澜｜考研政治知识库 - 副本\guanlan\docs\mayuan-compatibility-requirements.md`。

目前宿主已有登录/me/logout、收藏、笔记及基础进度；完整登录交接、马原对象类型及服务间学习摘要接口仍需宿主开发。服务端适配代码不等于这些宿主接口已经实现。

## 对接职责

- 观澜验证统一身份、提供稳定用户ID和权限。
- 马原保存知识内容、详细学习记录和复习计划。
- 马原产生带用户版本的绝对学习摘要，通过受限服务身份同步到观澜。
- 观澜展示摘要投影，旧版本不覆盖新版本，事件重试不重复累计。
- 收藏、笔记若使用观澜共享接口，以观澜记录为权威；接入前本地记录需迁移并明确冲突策略。

## 接入前确认

1. 精确配置身份服务地址与允许的浏览器来源，正式服务使用HTTPS。
2. 确认观澜用户ID及身份信息格式、令牌验证行为、停用与退出规则。
3. 实现和验证一次性授权码交接，或正式采用双方一致的身份协议。
4. 配置受限服务凭证、摘要请求格式与确认版本响应。
5. 验证深链接、反向代理路径和SSR/浏览器登录恢复。
6. 两个真实测试账号联调，检查越权、切换、退出、重试、旧版本及断网恢复。

登录令牌不得出现在URL、普通页面消息或日志中。前端展示的角色不能替代后端权限校验。

## V1 迁移

V1单文件数据没有账号身份。登录后应先查看导入摘要并确认归属，不把当前设备数据自动上传到首次登录的账号。旧自评、答题和浏览分别处理，保留历史记录的未验证标识。

## 验收声明

真实观澜登录、统一退出与云端摘要确认，只有经过真实接口联调后才可标记完成。开发模式登录、模拟HTTP接口或本地队列成功均不能替代这一验收。
