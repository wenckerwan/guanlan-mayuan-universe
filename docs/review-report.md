## Important

### I1. 导入较晚的练习会覆盖另一端的自评掌握

位置：`assets/core.js:67`、`assets/core.js:79`；自评写入位置 `assets/app.js:21`。

复现：A 浏览器在 t=100 将 matter 自评为 mastered；B 没有对该节点自评，在 t=200 完成关联题（其 mastery 为默认 unlearned）。把 B 的进度导入 A。recordAnswer 把 B 节点 updatedAt 设为 200，mergeProgress 据该时间选择 B 的 mastery，A 从 mastered 变成 unlearned。

复核使用独立 Node 最小案例实际得到 `{mastery:"unlearned",updatedAt:200,attempts:1}`，不是推测。较新练习不应取得修改掌握程度的权利。应给自评独立时间戳，处理旧版兼容，并确保明确的新自评可以降低掌握程度。

### I2. 价值实验的说明与图形未跟随模型条件

位置：`assets/app.js:144`、`assets/app.js:152`。

复现：社会劳动生产率滑块设为 0.5，数值为单位价值 20、数量 0.5 倍，但说明仍是“单位价值量下降，数量增加”。个别模式单位价值始终为 10，绿色条却按 `130/labFactor` 变化，暗示单位价值改变。滑块实时更新仅替换 visual 和 output，动态说明必须一起更新。

影响：同一实验同时给出相反结论，妨碍学习者理解社会/个别生产率。应根据模型输出生成升/降/不变说明，并按 r.unit 绘制与标明绿色条含义。

### I3. 框架回忆的“换一组”永远重复章节前三个概念

位置：`assets/app.js:187`、`assets/app.js:202`。

复现：打开任一模块，切到框架回忆，揭晓后连续点击“换一组”。每次 newRecall 虽重新选择 node，framework 固定为 `pool.slice(0,3)`，题目和对应概念保持不变。

影响：用户可见按钮没有实现承诺的换组，章节其他节点不能通过该入口成为框架题。让新 node 决定一组不同框架，或按章节轮换/抽样，并避免有足够节点时连续同组。

### I4. “客观假象 / 主观错觉”的表头变成了另一对概念

位置：`assets/data.js:158`、`assets/app.js:129`。

复现：在辨析台选择“客观假象 / 主观错觉”。数据关联宽概念 essence-phenomenon 和 reflection，页面直接取节点标题做表头，结果为“本质与现象 / 能动反映”；右列却把对应概念定义为“错觉是主体不正确反映”。

影响：视觉上把能动反映等同于主观错觉，是概念边界错误。比较项应能指定独立的左右显示标签；相关节点链接可以继续指向所关联的宽概念。
