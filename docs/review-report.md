# V2 独立审查报告

日期：2026-10-03。

审查结论：本轮发现的重要问题均已修复，并复查了最终源码及相应回归测试；在本机开发运行范围内，未发现需要阻止交付的未解决问题。此结论不等于 Hyperf/MySQL 容器或真实观澜集成已经验收。

## 审查范围与依据

依据 `platform-design.md`、`implementation-plan.md` 及观澜工程的 `docs/mayuan-compatibility-requirements.md`，检查了身份与账号隔离、来源校验、服务端判题、持久化、事件重放、版本冲突、导入、内容管理、摘要队列，以及学习控件是否执行实际操作。

本审查代理未修改实现文件，也未占用主代理的浏览器。浏览器及真实 HTTP 验收结果由主代理执行并反馈；独立执行的验证如下：

- `php tests/api/run.php`：32 条 PASS 断言全部通过，涵盖越权、判题、重放、导入、内容发布回退、摘要重试及捕获身份检查。
- `node --test apps/web/tests/*.test.mjs`：11 项全部通过，包含 4 项图谱测试及 7 项学习模型测试。
- 将 V2 两份初始内容与 V1 `assets/data.js` 逐集合深比较：7 章节、101 概念、126 关系、19 辨析、30 原创题及 13 来源均保留；新增内容版本标识不影响正文。
- 对首次发现的合法未来复习时间及无独立自评时间的旧版导入，执行过内存 SQLite 探针；修复后由回归测试覆盖。

## 重要修复复查

| 问题 | 最终处理 |
|---|---|
| 正式模式沿用旧开发管理员会话 | HTTP 入口及业务层拒绝正式模式中的开发身份；开发登录本身同样关闭。 |
| MySQL TEXT 无法容纳初始内容文档 | MySQL 使用 LONGTEXT；已有实验表的迁移语句记录在 API README。 |
| Hyperf 会话注入、方法及配置不符合 3.1 接口 | 改为 SessionInterface、migrate、正式 handler/options 配置及 ApplicationContext 注册；加入正式模式 Secure、Host-only Cookie 处理。仅完成源码核对和语法检查。 |
| V2 合法三天后复习日期导入失败、旧 V1 自评丢失 | 区分发生时间与未来到期时间；缺少自评时间的旧记录保守合并，不用最近答题时间代替自评时间。 |
| 多次快照导入重复历史答案、旧回忆影响到期数量 | 按历史答案 ID 去重；保留回忆事件历史，仅每个概念最新回忆参与到期统计。导入答案仍为未验证历史，不增加可信正确数。 |
| 摘要事件跨用户重号、旧确认覆盖新版本 | 事件 ID 包含用户命名空间；摘要事务内持久化，按版本确认；旧待发摘要可被新绝对摘要取代，限流及失败分类保留重试状态。 |
| 切换账号后的异步响应、批量回忆或离线事件串入新账号 | 捕获原账号和会话代次，阻止过期响应提交页面状态；离线记录保留原账号归属，批量动作在切换后中止。 |
| 另一标签页切换共享 Cookie 后，旧标签页提交到新账号 | 两个 HTTP 运行时对私有请求检查 X-Mayuan-User 与已验证会话身份；不一致返回 session_changed。该值仅作一致性前置条件，不用作认证依据。 |
| 答题响应丢失后重复计次、旧事件响应倒退页面状态 | 保留同一次作答的事件 ID 与原请求体；页面只接受不倒退的状态版本，队列排空后重新读取权威状态。 |
| 管理员编辑临时无效 JSON 导致渲染失败 | 安全解析编辑列表，保留可编辑原文并显示错误；切换内容类型同步重置字段选择。 |

Hyperf 核对依据为官方 [会话实现](https://github.com/hyperf/session/blob/3.1/src/Session.php)、[配置](https://github.com/hyperf/session/blob/3.1/publish/session.php)、[会话中间件](https://github.com/hyperf/session/blob/3.1/src/Middleware/SessionMiddleware.php)及[容器初始化](https://github.com/hyperf/hyperf-skeleton/blob/3.1/config/container.php)。

## 学习内容与实际功能

社会劳动生产率模型按反比改变单位商品价值量；个别劳动生产率模型保留社会决定的单位价值量。水相变注明标准大气压、平衡相态及潜热边界，生产关系实验明确不能用单一管理因素代替完整社会制度分析。自由文字回忆与改错仅提供自评依据，不伪装客观自动判分。

最终图谱包含七章节总览、章节概念、紧凑的跨章节聚焦、方向箭头、边界裁剪、平移缩放及可切换列表。跨章节连线只汇总已有关系；关系拼接台对未收录组合不武断判为理论错误。图谱聚焦、筛选、练习换题、回忆换组及实验条件均连接实际状态或计算。

主代理反馈已完成桌面浏览器学习记录、收藏笔记、服务端答题反馈、辨析改错、三实验、关系拼接、回忆与框架换组、第二账号空状态及管理员保存发布回退；390×844 视口下检查了列表、详情和笔记持久化，页面无横向溢出。真实 HTTP 测试包含共享 Cookie 切换账号后的拒绝行为。完整构建及交付验证以 `verification.md` 的最终记录为准。

## 明确保留的验收边界

- 主机无可用生产容器环境；Hyperf/Swoole/MySQL 的依赖安装、容器启动、生产代理与负载行为未实际验收。
- 真实观澜账号、一次性登录交接、统一退出及摘要服务未联调；不得称为已实现真实 SSO。摘要通道默认休眠，配置和模拟重试通过不能替代宿主验收。
- 浏览器文件选择上传被自动安全检查拒绝，主代理没有绕过限制；导入预览代码和真实 API 备份恢复已验证，但不能把完整浏览器上传流程标记为通过。
- 审查不宣称材料覆盖全部考研知识点，也不宣称完成大规模多用户压力测试。
